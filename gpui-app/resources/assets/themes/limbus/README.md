# Limbus 主题占位图（原创自绘 v2）

本目录图片由 `scripts/generate_limbus_theme.py` 程序化生成，
铆钉标签框 / 暗红金属条 / 警示纹 / 印章均为原创绘制，
**不含 ProjectMoon 官方素材**，可随仓库按 AGPLv3 分发。
配色数值（金 `#D8A800`、暗红 `#4A1010`、冷黑底）为从官方美术采样
的色值灵感，不构成复制。

| 文件 | 用途 | 尺寸 | 渲染约束 |
|---|---|---|---|
| `bg.png` | 主背景（冷黑+暗蓝星云+裂纹，低不透明度垫底） | 1600x900 | 铺满窗口，低透明度，允许非等比；**不含任何页面装饰元素** |
| `divider.png` | 芥末金分隔线（透明底） | 1200x26 | **仅按原始比例缩放**，固定 120px 宽 |
| `seal-red.png` | 血红印章点缀（透明底） | 256x256 | 固定正方尺寸 |

> 背景底板被拉伸到窗口尺寸，因此**不在其中烘焙任何页面装饰**
> （底部金色横线与警示斜纹已移除：它们会浮在窗口 97% 高度处、
> 且被纵向拉伸）。装饰属于控件，不属于底板。
>
> 卡片头暗红金属条与铆钉边框**不再作为位图提供**。
> 800x72 的金属条被拉伸到卡片宽度后铆钉与血污会发生形变，
> 256x256 的边框瓦片也无法在任意尺寸下保持比例，
> 因此两者改由 `gpui-app/src/components/base.rs` 以程序化几何绘制
> （渐变 + 定点血污椭圆 + 强调色角框），可随窗口与强调色自由变化。

重新生成：`python3 scripts/generate_limbus_theme.py`
（每个素材独立播种，增删素材不会改变其它素材的随机流。）
