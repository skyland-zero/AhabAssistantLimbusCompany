# User Guide

## Quick Start

1. Create a lineup on the **Teams** page, pick sinners and an accessory scheme
2. Go back to the **Console**, add a task and bind it to a team
3. Click ▶ on a task card — progress and logs stream live on the right

## Task Types

- **Mirror Auto**: fully automatic mirror dungeon runs with team rotation
- **EXP Dungeon**: auto Luxcavation with configurable repeats
- **Daily Rewards**: claim daily / weekly rewards and mail

## After Completion

Configure what happens after the whole queue finishes, at the top-right of the Console:

- Do nothing
- Close game
- Shut down
- Custom command (e.g. `shutdown /s /t 60`)

## Toolbox

- **Auto Battle**: loop battles until stopped manually
- **Enkephalin Module**: convert Lunacy automatically to prevent overflow
- **Screenshot Tool**: capture the current game window

## FAQ

### Window not detected?

Run the assistant as administrator and make sure the game window is not minimized.

### Supported resolutions?

Common 16:9 resolutions are supported; 1280×720 or above is recommended.
