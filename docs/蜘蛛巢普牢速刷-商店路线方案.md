# 蜘蛛巢普牢速刷：商店与路线方案

> 对应预设：`spiderweb_family_normal_farm`
>
> 对应路线：`spiderweb_family_normal_farm_route`

## 1. 背景

当前 10 人蜘蛛巢全家桶沿用了 `hos_ryoshu_solo_route`，并把 5 层商店全部跳过。实际日志显示：

```text
总耗时 28:03
战斗   18:48
商店   00:16
寻路   01:04
```

慢点主要在战斗，而不是商店。全跳商店意味着：

- 良秀不换 S1/S2→S3；
- 不合明镜止水；
- 不拿斩击四级；
- 不强化呼吸/斩击小件。

良秀伤害不足，单场战斗回合数被拉长，最终比进商店更慢。

## 2. 攻略依据

参考：

- 光翼展开怪《镜牢速刷攻略：赛季高光小蓝良伪单通 5 层速刷全解》
- 绅士丶蚂蚱《镜7 刃良深度攻略，均时 13 分》
- NGA / TapTap 的普牢商店、融合与强化思路

攻略给出的普通 5 层路线：

```text
普通卡包 → 绝望包 → 2 号线
平均 13:27
```

核心商店步骤：

1. 看到良秀可替换技能就换成三技能；
2. 免费刷新一次，必要时再刷，建议不超过 2 次；
3. 2 个三级 + 1 个二级合成四级；
4. 优先明镜止水，其次斩击四级或美感；
5. 强化对速刷有用的小件；
6. 无用饰品可以卖，但自动化默认不卖以节省时间。

目标四级：

| 饰品 | 作用 | 优先级 |
| --- | --- | --- |
| 明镜止水++ | 暴击倍率 1.2→2.5，暴击后下回合 +10 攻击等级 | 必做 |
| 破碎的巨剑 | 斩击基础技能拼点 +2，斩击增伤 | 高 |
| 切开的记忆 | 斩击硬币威力 +1，拼点胜利 +30% 伤害 | 高 |
| 美感++ | 对负面状态敌人 +35%，沉沦额外 +10% | 可选 |
| 呼吸石 | 拐三千大世界 EGO | 最后做 |

有用小件：

```text
鲜血装饰+
纠缠绳索++ / 偏振光++
锈蚀的纪念币
雾化吸入器
四叶草
脑啡肽试剂组
暗焰烟斗
```

开局：

- 星光：起始之星 + 星际旅行；
- 观测：赤红纠缠的蜘蛛巢；
- 石冢：要么不强化，要么强化到 ++。

## 4. 路线主题包

| 楼层 | 主题包短别名 | 说明 |
| --- | --- | --- |
| 1 | `unloving` / `automated` / `dregs` | 无慈悲、自动工厂、宅邸 |
| 2 | `chick` | 地狱鸡，拿三级合成材料 |
| 3 | `certain` / `bones` / `degraded` / `addict` | 某个世界、肉斩骨断、堕落的忧郁、沉迷的色欲 |
| 4 | `Hatred` 优先，其次同第 3 层 | 憎恶与绝望 |
| 5 | `line` | 2 号线 |

注意：权重表使用的是短键，完整中文/英文名只用于展示。路线必须优先匹配短键，否则会退回普通权重。

## 5. 路线饰品

| 饰品 | 楼层 | 优先级 | 保护 |
| --- | --- | --- | --- |
| 明镜止水 | 1–5 | 1 | 是，必做 |
| 破碎的巨剑 | 3–5 | 10 | 是 |
| 切开的记忆 | 3–5 | 20 | 是 |
| 美感 | 3–5 | 30 | 是 |
| 雾化吸入器 | 1–5 | 40 | 否，可作合成材料 |
| 四叶草 | 1–5 | 50 | 否，可作合成材料 |
| 脑啡肽试剂组 | 1–5 | 60 | 否，可作合成材料 |
| 暗焰烟斗 | 1–5 | 70 | 是 |
| 鲜血装饰 | 1–5 | 80 | 是 |
| 锈蚀的纪念币 | 1–5 | 90 | 是 |
| 石冢 | 1–2 | 100 | 是 |
| 老旧木雕人偶 | 1–2 | 110 | 否 |

雾化吸入器、四叶草、脑啡肽试剂组标记为不保护，是为了让“只合成呼吸体系饰品”流程能把它们当合成材料，去赌明镜止水；最终四级仍然保护。

## 6. 商店流程

预设默认只进 1–3 层商店：

1. 技能替换：良秀首位，模式 3（全换 3，先 2→3）；
2. 购买路线饰品；
3. 只合成呼吸体系四级；
4. 强化路线饰品、本体系四级和呼吸小件；
5. 不治疗、不出售；
6. 4–5 层商店直接跳过。

## 7. 预期与限制

- 目标先把 28 分钟降到 18–20 分钟；攻略的 13:27 是手动操作，自动化很难完全复刻。
- 10 人全家桶第一层献祭 9 人，理论上比 7 人版慢；如果实测仍然慢，可以后续再加一套 7 人速刷预设，共用这条路线。
- 第一次实机跑可能需要补中文/英文饰品别名或图标，尤其是“美感”“呼吸石”“纠缠绳索/偏振光”这类翻译差异。
- 这条路线只支持普通 5 层，不处理困难 15 层。
