# Local UI icons

The path data in `Controls/IconCatalog.cs` is derived from the official Lucide SVG icons:

- https://lucide.dev/icons/
- https://github.com/lucide-icons/lucide

Only the paths needed by this Avalonia frontend are kept locally. No Lucide runtime package
or third-party UI component library is referenced by the project. Lucide publishes its icons
under the ISC License; retain this notice when redistributing the derived icon data.
