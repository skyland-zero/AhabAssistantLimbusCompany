# 使用帮助

## 快速上手

1. 在「队伍」页面创建编队，选择人格与饰品体系
2. 回到「主控台」，添加任务并绑定队伍
3. 点击任务卡上的 ▶ 启动，进度与日志会在右侧实时显示

## 任务类型

- **镜牢·自动挂机**：全自动坐牢，支持多队伍轮换与循环战斗
- **经验本**：自动刷 Luxcavation，可设置重复次数
- **每日领奖**：领取日常 / 周常奖励与邮件

## 完成后动作

在主控台右上角可以配置队列全部完成后的动作：

- 无动作
- 关闭游戏
- 关机
- 自定义命令（如 `shutdown /s /t 60`）

## 工具箱

- **自动战斗**：循环战斗直至手动停止
- **体力换饼**：自动将狂气转换为体力并合成脑啡肽模块，防止体力溢出
- **辅助截图**：截取当前游戏窗口画面

## 常见问题

### 窗口识别失败？

请以管理员身份运行本助手，并确保游戏窗口未被最小化。

### 支持哪些分辨率？

支持常见 16:9 分辨率的游戏窗口；建议使用 1280×720 或以上。
